# Fonts

`archivo-latin-wdth112-wght800.woff2` is Archivo (Omnibus-Type) as served by Google Fonts for
`family=Archivo:wdth,wght@112,800`, latin subset. It is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows self-hosting.

Only this one instance is used (every heading is weight 800 at 112% width), so it is 37 KB instead of
the 90 KB full variable font. Public Sans and JetBrains Mono are still loaded through `next/font/google`
in `app/layout.tsx`.
